# Playwright Test Automation Framework

This project is an end-to-end UI test automation framework built with Playwright and JavaScript. It is designed for reliable, scalable, and maintainable testing of web applications.

## Tech Stack

- Playwright
- JavaScript (Node.js)
- npm

## Project Structure

tests/ # Test files
pages/ # Page Object Models (POM)
utils/ # Helper functions
fixtures/ # Test setup and fixtures
playwright.config.js
package.json


## Installation

Clone the repository:

```bash
git clone <repo-url>
cd <project-folder>


npm install
npx playwright install
```

## Run all tests:
```bash
npx playwright test
```
